# Weave 浏览器本地版

## 项目素材画布

打开项目「素材库」，在分类与排序工具栏右侧切换「网格 / 画布」。画布按项目独立保存；可把已有素材从「未摆放」栏拖入、自由移动和缩放，框选素材后建立命名区域，也可以添加便签。拖入本地文件会先按正常导入流程保存，再摆到画布；画布上的素材仍引用项目原片。移出画布只取消布局，不会删除资产；真正删除仍在素材库的回收站操作。

鼠标滚轮平移、Ctrl/触控板捏合缩放；选中区域可移动、折叠、锁定，支持撤销/重做。未摆放栏中的素材不会被自动整理；画布视图只是该项目素材库的另一种浏览与组织方式。

素材库默认不显示空的旧「分镜 / 脚本」分类入口；已有旧分类素材仍可通过原记录访问，对应分类在有素材时保留。

## 公司电脑使用前

公司已提示「被管理员或安全策略阻止」时，先由 IT 审核允许的使用方式。这份 HTML 是独立浏览器交付，不是改名的 EXE，也不启动 Electron、命令行或本地服务。请勿改安全策略、关闭杀毒或通过脚本运行被拦截的程序。

- 若公司允许使用本地 HTML：用公司允许的 Edge / Chrome 打开 `Weave.html`。不需要 Weave、Node、npm、管理员权限或安装扩展。浏览器本身仍由公司管理，不能保证每台受管电脑都允许打开或存储。
- 若不允许本地 HTML，或打开后存储被限制：请 IT 将「内网部署」文件夹中的 `index.html`、`app.js`、`app.css` 放到获批的 **HTTPS 内网站点**。客户端只访问网址，不执行 Weave.exe。普通内网 HTTP 可能缺少安全上下文，导致文件哈希等功能不可用；不要用关闭浏览器安全检查的参数处理。
- 本机开发预览地址 `localhost` 只能在运行预览服务的这台电脑使用，不能复制给公司电脑当作线上网址。

## 保留的能力

左侧「全部项目」下面的「待整理」是本机跨项目中转区（原名公共收件箱），不是团队共享空间。旧收件箱直接沿用原项目编号、素材和位置，只更新界面名称；新素材可在接收栏选择待整理，之后通过「加入项目」分配。团队复用图片仍在「公共资产库」。

「通知」独立放在侧栏下方、设置上方，显示公共资产库新增素材及未读数量，可点入实际新增素材。它不是软件升级或个人项目活动；连接公共库后才有对应内容，关闭页面不持续监控。

通知现在是独立保存的记录：首次连接建立历史基线，只将之后的他人新增记为通知；自己的收录不重复提醒。同类别一分钟内发现的新增合并显示，支持全部/未读、标为已读/未读与全部已读；点击「查看素材」定位该批真实资产。已读状态随本机匿名客户端和公共库分别保存，同源窗口同步；断开/切库不删除旧通知。素材后来被移除或暂不可访问，通知仍保留并说明原因。浏览器数据被清除会影响这些本机通知状态，不会把它们写到公司共享盘。

网页打开期间收到新公共素材，侧栏未读和软件内提示不依赖系统通知权限。「通知 → 系统提醒」可主动申请权限、开关并发送测试，此处修改即时保存；总设置里的更改仍需保存设置。只在浏览器允许且切到其他窗口时提交系统提醒，点击提醒会返回通知页，未保存文稿仍会提示。前台/关闭/阻止/失败不会冒充已送达；提交成功仅代表交给浏览器，不保证 Windows 横幅可见。支持 Web Locks 时同源窗口串行提交，避免同一批重复系统提醒。不同浏览器、来源地址或设备不共用本机已读状态。

素材库分类包括角色、场景、道具、分镜、脚本、视频、音频、其他，另有未分类收件状态。道具保留；「其他」用于已整理的杂项，与「未分类」不同。分类卡片不再带小箭头，宽屏八列，中等窗口四列、窄窗口两列。音频为橙棕色、其他为石板蓝灰色；颜色同步用于卡片边框、分类入口与筛选。

新导入的未指定分类音频自动归为音频；旧音频不强制改写记录，也可通过音频入口筛选、试听和加入剪辑段落。「音频」「其他」均可手动拖入或批量归类，目录保存、工程校验和备份保留分类；不转换原片。公共库仍只收录图片，新增「其他」图片分类，不接受音频文件。旧 EXE 没有因此自动更新；新分类记录请使用本次浏览器交付打开。

创建和切换项目；导入、拖入、粘贴实际文件；方形/原始比例网格；预览与分类、标签、提示词；剪辑对照、段落素材引用与独立交接包；保留旧镜头与分镜拼图导出；回收站；ZIP 项目导出。网页直链仍受浏览器跨域及目标网站登录限制，受限时下载实际文件再导入。

## 剪辑对照（2026-10-16）

素材卡片现在使用安静缩略图，播放器控制只在放大后出现。素材库或剪辑对照中，鼠标停在图片、视频、音频上按空格快速预览；再按空格、Esc 或点击遮罩关闭，输入正文时的空格不受影响。「标记完成」仅处理整段；选中文字仍可批注，不再支持局部标记完成。旧局部标记不再显示，但工程原记录和完整备份不强制清除。

视频可以拖到另一张视频卡片上形成堆叠，或直接把新视频文件拖到卡片上导入并合组。卡片角落的版本数打开历史，可设/取消最终稿或移出堆叠，原片不删除。没有最终稿时最新版本置顶；内部归类、跨项目复制/移动、文稿关联带整组，文稿中的主选仍独立于最终稿。后续入栈会补充到已关联该组的段落。

接收栏「导入时命名」默认开启、在本机记住选择；曾主动关闭的选择保留。打开后手动拖入/选择/粘贴图片会先弹出批量命名，扩展名保留；取消不导入。授权目录项目按新名字保存受管理副本，素材库与导出同步使用新名字，原始拖入来源不改名。只保存在浏览器缓存中的项目没有可同步改名的本地实体文件；请先在设置保存到目录。后台目录扫描不弹命名窗，重复内容仍按既有去重规则跳过，不借机改名旧素材。

音频在素材库与剪辑对照使用横向卡片。可见的 8 MB 以内 PCM WAV 原片进行有限采样，显示波形与时长；不解码全部大音频，其他格式/不可读文件显示明确标注的波形示意，并非真实振幅。试听仍使用完整原文件。全屏拖入提示增加捕获阶段收尾、Esc、焦点/页面切换及过期清理，不改素材文件。

原始比例视图使用宽窄混排：角色为紧凑窄卡，场景和视频使用宽卡；其他横向图片也可用宽卡。紧凑模式的角色预览限高 184px，宽卡限高 260px，舒适模式分别为 230px/320px。限制的是浏览容器，完整画面仍等比居中显示，不裁切、不修改分类或原文件。窗口变窄时宽卡退回单列，方形网格保持原有统一尺寸。

音频卡片可见时预读 32 MB 以内原文件，核对大小与已有 SHA256；在拖拽开始时同步加入 File 数据，不再只传下载链接。最多并行准备 2 个、缓存 8 个且合计不超过 64 MB，按素材身份/哈希/名称/地址区分，不改原音频。未就绪、大文件、受限的数据存储继续保留兼容拖出与原文件下载。脚本构造的 File 不等同操作系统原生文件桥接，跨页面/浏览器进程仍可能被丢弃，尚不能保证直接拖进即梦；没有向外站自动上传。可靠替代仍是下载原文件，再在目标网页选择上传，或尝试从资源管理器拖入。

原「镜头工作台」入口替换为「剪辑对照」：粘贴整篇文稿，按空行/换行分段；图片、视频、音频放在段落旁边。支持主选/备选、整段标记完成、引用批注、已处理状态、段落拆分/合并/排序/移除与恢复。素材库多选后也可直接加入剪辑段落。旧镜头不删除，明确点击后才复制为段落，私有 Prompt 不默认带入。

已有素材拖入只建立引用，不重复复制；本地文件导入保存原片再关联。音频新增 MP3/WAV/M4A/OGG/FLAC 保存与试听，具体编码仍受浏览器解码支持限制。文字编辑需点「保存文字」，批注需点「添加批注」，未提交输入不能视为已保存。

「导出视频 / 交接」可选择按段落编号打包关联视频，或生成静态对照页、文稿、清单及关联原片 ZIP；交接包完整解压后打开 `剪辑对照.html`。交接包不包含移除段落、未关联素材、原始粘贴历史或私有 Prompt，也不是完整工程备份。关联媒体总计上限为 300 MB。

## 本地项目 + 共享公共库（2026-10-16）

这次新增了两套独立的目录连接，不需要新建服务器或账号。**需要浏览器提供目录选择并由使用者授权**，还需要 Windows 本身允许访问该目录。公司 Chrome、本地 HTML 和实际 SMB 共享盘的授权及并发行为尚未完成现场验收；先用空测试目录，不要直接搬走唯一一份真实工程。

1. 在「设置 → 本地项目目录」选择新项目保存目录，之后新项目在其下创建独立文件夹；默认位置可以再次更改，不自动搬迁旧项目。「更改当前项目保存位置」会在所选位置内新建文件夹，复制并校验完整目录（已有目录项目含历史、回收站），保持项目身份，成功后切换，原目录不删除。浏览器本机项目也可用此入口保存到目录。「当前项目另存到目录」则是创建新身份的独立副本，含义不同。搬迁后只编辑新位置，不要同时编辑留下的旧副本。
2. 在「公共资产库 → 连接共享文件夹」选择一个团队共用的文件夹并授权读写；同事选择同一个文件夹。首次连接会创建 Weave 管理文件并逐步复制收录已有图片，原始文件保留。软件中对受管理副本的改名、分类和移入回收站会反映到共享文件夹；已有外部原图的改名、移动或删除尚未双向同步，不能把此功能当作文件夹镜像。旧只读关联仍可使用，可重新选择该目录建立可写公共库。更换公共库不会自动合并旧库。
3. 在项目选中图片，点击「收录到公共库」；公共库选中图片，点击「加入当前项目」。两边都是原文件的独立复制，不改变图片编码质量。发布不附带项目名、脚本、Prompt 或标签；项目复用时保留公共库编号、资产编号、版本和 SHA-256 来源信息。

公共库包含产品、角色、场景、道具、分镜、未分类，主要管理图片；生成视频留在个人项目。分类和改名也反映到中文文件夹里，文件带唯一编号防止同名覆盖。`_Weave` 保存提交、历史原片和回收站，不能当临时缓存清理。原片分类后可能保留恢复副本，会占用额外空间。受管理文件请通过软件整理，外部改名、移动、修改内容可能导致读取失败，不会用缓存静默覆盖磁盘。

### 目录更新规则

- 网页打开且有目录授权时，个人项目与公共库约每 20 秒检查，回到窗口也检查；个人项目可在设置点「立即检查目录」，公共库可点刷新。浏览器可能限速、冻结后台页面；不是关闭网页后的后台服务。剪辑文字或批注尚未保存时，个人项目自动检查暂缓，避免刷新冲掉输入。
- 向已连接的项目/公共库文件夹直接放入新文件，会在连续两次检查确认大小/修改时间稳定后自动收录，通常需 20–40 秒；复制仍在进行时继续等待。角色、场景、道具、产品、分镜、脚本、视频目录用于识别分类。项目支持图片、视频、音频、文档；公共库只收录图片。导入原文件字节不做重编码，源文件留在原处，软件另外保存受管理副本，因此会增加磁盘占用。
- 相同内容不重复入库，已移入回收站的内容也不因来源文件还在而重新出现。外部来源文件替换成不同内容，收录为新素材，旧素材及段落引用保留；外部来源删除不连带删除已入库副本。这是非破坏性收录，不是资源管理器的双向删除镜像。
- 已带 Weave 编号的受管理原片、`_Weave`、隐藏目录、`导出`/`备份`、嵌套工程不作为新下载重复收录。受管理原片直接改名、移动、损坏只报异常，不自动修复或用缓存覆盖。软件内的改类、改名仍同步写入可读文件夹。
- 自动扫描最多一万项/12 层；单文件自动收录上限 300 MB，一批最多 100 文件/500 MB，余下分批检查。超限或格式不兼容会提示，请改用手动导入。当前实现仍需要读取历史记录与校验原片，大型视频项目/万张原图库没有完成性能验收。
- 浏览器只提供授权文件夹的名称，不能凭空显示完整盘符/UNC 路径；实际位置以系统选择器选择为准。授权撤回、共享盘离线、未知格式或校验冲突会提示，不能将缓存显示当作目录保存成功。公司原生目录权限、SMB 跨机并发仍需现场验证。

公共库新增采用各自独立的提交文件，不把 SQLite 或一份反复覆盖的总清单放到共享盘。修改同一资产有版本检查及冲突选择入口，保留双方历史。常规重复收录会按内容跳过；两个客户端恰好同时收录相同内容时，可能出现可分别管理的重复项并提示，不承诺跨机器原子去重。断网、授权撤回或不兼容格式会报错；需要真实 SMB 验收，不是数据库级事务保证。

「公共库更新」显示分类汇总和素材入口，不展示使用人姓名。首次连接建立历史基线；之后在网页保持打开时约每 20 秒检查一次，切回网页也会刷新；后台页面可能被浏览器限速。自己的客户端不弹新增提醒，系统提醒仍需手动授权，关闭网页不持续监控。

本地目录项目以文件夹为保存依据；浏览器 IndexedDB 仍保留完整工作缓存，因此也占浏览器存储额度。清除缓存后需重新授权并打开目录。目录写入失败不会报告保存成功；无法确认目录时只显示带警告的旧缓存。不要将私人项目和公共库选成相同或嵌套目录。

当前新增目录格式与旧 EXE 的原生项目格式不同，不要交替用旧 EXE 直接编辑新目录。目录项目之间可以复制/移动，先保存目标再处理来源；第二步失败时保留源和已保存的目标并明确报错，不宣称跨目录原子事务。没有自动迁移旧工程，也没有承诺所有旧版本相互兼容。

## 字体

应用内文字统一使用包内的 HarmonyOS Sans 鸿蒙字体，无需安装系统字体，也不会从 CDN 加载。单文件 `Weave.html` 内嵌完整原版 Regular / Medium / Bold 字体，因此体积约 34 MB；「内网部署」目录使用附带的 `fonts` 文件夹以便浏览器缓存，请保留整个目录。不要只复制 `index.html` 或 `app.css`。设置中可查看字体署名与完整许可，压缩包也保留原始许可文件。

Windows 原生标题栏、文件选择对话框、浏览器自身菜单和网页内 PDF 自带的字体不由应用 CSS 控制；超出字体覆盖范围的特殊文字或表情也可能由平台回退显示。分镜板导出文字会等待包内字体加载完成后生成，不改变原素材。

字体来源：[华为官方设计资源](https://developer.huawei.com/consumer/cn/design/resource-V1/)。

## 把素材用于生成工具

在素材库选中素材，点击底部「用于上传」，或右键选择同名操作。

视频卡片悬停提供下载/拖出图标，拖出仅携带当前置顶/最终稿，不把所有备选发到外部。浏览器新增 Chromium 单文件 DownloadURL 拖放兼容路径，这是非标准能力，不是 Windows 原生文件桥接；尚未在用户实际剪辑软件验证。目标不接收时，点击下载原片，再从下载记录或资源管理器拖入。剪辑长期使用的原片请保存在固定目录，不依赖浏览器临时下载位置。图片拖放继续保留浏览器原生数据，不套用视频这条路径。

- **直接拖图片本身**：从素材库或此窗口中的实际图片开始拖动，不拖卡片边框、文件名或按钮。图片现在使用浏览器原生 img 拖放，Weave 只追加内部整理用的 ID，不清除浏览器数据、不添加脚本构造的 File、不用 Blob/Data DownloadURL 代替原生图片。外部一次一张；多选仅用于 Weave 内部归类与镜头关联。没有「准备完成」或「拖出文件」按钮，也不在悬停时预读原片。视频与文档不承诺直接拖到外站，请下载原文件。
- **复制图片**：在支持粘贴图片的目标页面按 Ctrl + V。复制完整画面，不使用方形缩略图；非 PNG 转成 PNG，动态图只复制静态帧，原文件不改变。权限受限或网站不支持图片粘贴时改用文件上传。视频不承诺剪贴板粘贴。
- **下载原文件**：不需要导出整个工程，也不做截图压缩。下载后从浏览器下载列表（若支持拖放）或文件资源管理器拖入目标上传区域，或在目标网站选择该文件。页面显示「已请求下载」不代表系统已保存或网站已上传。

不会自动向 Seedance、可灵或任何外站上传。内部分类和镜头拖放仍优先使用素材引用，不重新复制原片。

浏览器实现依据：[MDN 拖放数据与兼容性](https://developer.mozilla.org/en-US/docs/Web/API/HTML_Drag_and_Drop_API/Drag_data_store)、[MDN 剪贴板权限与支持](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API)。不同浏览器之间的原生文件拖放不等同于网页内部的 `File` 数据，必须在实际环境验证。

## 与桌面版的区别

- 没有后台下载目录监听、关闭网页后持续接收或系统托盘。已连接可写公共库时，在网页打开期间可检查同事新增并提供可选提醒。
- 不会自动读取桌面版的项目目录或数据库，也不能直接把旧桌面项目文件夹当作浏览器目录项目打开。完整备份 ZIP 可以通过浏览器的「恢复备份」校验并恢复；请保留旧项目和原备份。
- 内网站点只分发应用页面，不等于多人共享项目服务。公共库共享依赖每人明确授权同一个实际目录，不会因为 HTML 放在一起就自动共享，也不提供服务器推送。
- 浏览器可在授权后直接保存新的目录项目，也保留原来的浏览器本机模式；详见上方双目录流程。ZIP 导出可用于获批桌面端的旧格式交付。

## 浏览器通知

在「设置 → 浏览器通知」点击「开启浏览器通知」，再由你在浏览器弹窗中选择允许。网页不能替你批准，也不能解除企业策略阻止。权限按站点保存，不会随 HTML 一起迁移。

允许后可发送测试通知。提示「已提交」只代表调用成功，不保证 Windows 显示横幅；浏览器设置、系统勿扰和公司策略都可能影响显示。保存设置后，切去其他窗口时导入 / 导出完成或失败会提醒；前台操作不重复弹出，通知正文不包含项目名、文件名或素材。导出提醒表示已生成 ZIP 并请求下载，是否保存请查看浏览器下载列表。

当前通知依赖网页保持打开；关闭标签页、浏览器冻结页面或电脑休眠后不保证及时执行。不包含后台推送服务或操作系统级共享盘监听。可写公共库检查提交和目录新图片；只读关联检查当前图片内容。外部文件操作无法识别是谁操作，统一作为目录更新，可能提醒收录它的本机；通过 Weave 主动发布仍抑制本客户端自己的提醒。通知通常要求安全上下文；HTTPS 可用性仍受权限和企业策略限制，本地 HTML 的授权兼容性不保证。网页内错误和任务结果不依赖系统通知权限。

依据：[MDN 通知授权](https://developer.mozilla.org/en-US/docs/Web/API/Notification/requestPermission_static)、[MDN Notifications API](https://developer.mozilla.org/en-US/docs/Web/API/Notifications_API)。

## 数据保存与备份

原有浏览器模式的项目元数据和原始素材保存在当前浏览器的 IndexedDB，**不是 HTML 文件内部**。新连接的目录项目另有完整落盘记录与原片；公共库在单独授权的目录里。复制 HTML 不会复制项目；也不会自动上传素材到服务器。不含账号、云同步、遥测或自动 AI 请求。只有主动导入网址时才会请求该素材地址。

定期打开「导出项目 → 完整备份」创建 ZIP，包含项目记录、原片、回收站、文稿历史及画布等数据；生成前会回读校验，请在浏览器下载列表确认文件已保存。需要恢复时，在「全部项目 → 恢复备份」选择 ZIP，检查校验结果和内容数量后恢复为独立项目，不覆盖原项目。「交付导出」与剪辑交接包只包含所选内容，不能当作完整备份。浏览器 ZIP 恢复上限为压缩包 512 MB、解压后 1 GB；较大项目可在设置中使用「当前项目另存到目录」，然后备份整个目录，包括 `_Weave`。目录功能需要浏览器支持及明确授权。

请勿仅依赖浏览器缓存：清除网站数据、公司策略清理、隐私模式、换浏览器、换站点地址或改本地 HTML 路径都可能导致旧数据不可见或被删除。固定使用同一个浏览器配置与同一个获批网址。公共库需要单独备份；收藏、保存的筛选和位置记忆属于本浏览器的个人设置，不包含在项目备份中。文稿历史有数量和大小限制，不代替异盘备份。更新应用代码不主动搬迁或清空数据，但这不等于所有升级/磁盘故障场景已经验证。不要把 HTML 放到会被别人替换的公共可写位置；有修改权限的人可以修改页面代码，并在你下次打开时接触同源数据或已授权目录。

## 给 IT 的部署信息

- 单个 `Weave.html` 包含页面、样式和脚本，不需要 CDN、后端 API、外部字体或运行时下载。可以配置为站点默认文档，或通过固定路径访问。
- 需要 JavaScript、IndexedDB、Blob URL、Web Crypto、文件选择与下载；剪贴板功能依赖浏览器授权。双目录功能另需 File System Access 目录授权与本地项目 Web Locks；Windows 共享访问权限仍由公司设置。没有这些能力时不会冒充保存成功或通过脚本绕过策略。
- 可使用独立的内部 HTTPS 域名/路径，并遵守企业的脚本和内容安全策略。「内网部署」目录使用外链脚本/样式，不需要 CDN；还可使用项目常规构建的 `dist/client`。具体 CSP（包括用户素材的 Blob 预览、运行时样式）需由 IT 按实际应用审核，不要放宽整个浏览器的安全策略。
- 发布时只发布应用文件，不放用户原始素材、项目目录或开发环境凭据。未获得授权时不要发布到公网。
- 同源存储按浏览器来源隔离，换域名、端口或协议不会自动迁移数据。

依据：[Microsoft 应用控制](https://learn.microsoft.com/en-us/windows/security/application-security/application-control/app-control-for-business/)、[MDN 浏览器存储来源隔离](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API/Using_IndexedDB)、[本地文件的来源差异](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Same-origin_policy)。本地验证不能代替公司策略审批。
