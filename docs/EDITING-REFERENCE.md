# 剪辑对照

## 从这里开始

1. 进入项目，点击左侧「剪辑对照」→「粘贴整篇文稿」。选择按空行或每行分段，预览后点「开始整理」。后续粘贴只追加，不覆盖已有段落。
2. 点段落旁的「添加素材」，从右侧项目素材栏拖到对应段落，也可选定目标段落后点素材的加号。素材栏可按名称搜索，筛图片、视频、音频；不用时关闭。
3. 本地文件可直接拖到段落；也可在素材栏点「导入到本段」。图片可放大，视频和音频可播放。项目已有素材只增加关联，不复制原片；同一素材可服务多段。在素材库多选媒体后，也可通过「加入剪辑段落」批量关联。
4. 视频版本堆叠时，置顶版本用于默认展示；同一素材可以关联到多个段落，关联不复制原片。
5. 已做完的段落点「标记完成」。选中文字后可复制、拆为独立段或添加批注，不支持局部完成标记。正文修改后需重新确认整段完成状态，已保存批注中的原引用文字保留。旧局部标记保留在工程备份中，但界面和新交接页不再显示。

段落旁默认显示素材缩略图和按需操作，视频/音频不常驻播放器控件。悬停媒体按空格放大，空格、Esc 或遮罩关闭；全画面预览不使用方形裁切。

视频版本在素材库拖到另一视频上即可合组。拖整组到段落，版本都会关联；点击版本数查看历史、预览、指定最终稿或移出。后续新增版本会跟随已有组引用，不覆盖本段主选。最终稿决定组在素材库的置顶版本，本段主选只影响本段。解除该组关联会移除整组引用，但不删除原片。交接导出带上关联的全部版本，静态页逐条显示，不依赖 Weave 版本历史弹窗。

直接点击段落文字即可编辑，输入后短暂停顿或离开文本时自动保存；保存失败会提示重试。批注需点「添加批注」。文稿名称在离开输入框时保存。

## 整理与恢复

- 使用段落上的上下箭头或拖动把手调整顺序；点击段落编号并按住 Shift 点击另一编号，可选择相邻段落后合并。
- 拆段：将光标放在正文的目标位置，点击剪刀。原段保留素材关联，新段不自动复制关联。选中一段文字后，也可通过浮动工具将其拆成独立段；新段从无关联素材开始。
- 合并会保留两段素材和批注；若两段都有主选，沿用前段主选，其余为备选。被合并的后段原记录保留在已移除列表。
- 顶部「更多 → 已移除段落」可恢复；合并后恢复会重新出现原后段，应自行检查重复文字。解除素材关联不删除原片。素材移入回收站后，文稿显示不可用，恢复原素材即可重新查看。
- 「更多 → 原始文稿」保留每次粘贴时的全文副本，不因为拆并段落而更改。
- 剪辑对照中的编辑、拆并、排序和素材关联等操作支持 Ctrl+Z 撤回、Ctrl+Shift+Z 重做；文本输入时保留浏览器的文字撤回。文稿历史可查看并恢复旧版本，最多保留 40 个版本、总计约 12 MB，连续输入可能合并记录。
- 旧镜头没有被删除。可明确点击「复制旧镜头为段落」，原描述、对白、Prompt 和引用仍留在旧记录。复制可重复点击而不重复创建已经转换的镜头；新文稿默认不复制私有 Prompt。

## 音频

支持 MP3、WAV、M4A、OGG、FLAC 导入、原片保存、试听、引用和导出。浏览器端检查基本文件签名，不转码；具体编码能否播放由当前浏览器决定，不能解码时可下载原文件。素材库已有独立「音频」分类入口，新导入默认归入音频，旧音频也能筛出而不强制改写旧记录；剪辑素材栏仍可筛音频。授权目录项目按分类保存到「音频」或手动指定的其他目录。

## 交给剪辑

点击「导出视频 / 交接」可选择「视频原片」，按段落顺序将关联视频编号打包到同一个文件夹；同段多个视频使用类似 `01-1`、`01-2` 的编号。选择「文稿交接包」导出 ZIP，包含：

- `剪辑对照.html`：文稿、生成标记、批注、主选和备选，可以用浏览器查看。
- `文稿.txt`、`交接清单.json`：当前段落及文件对应关系。
- `素材/图片`、`素材/视频`、`素材/音频`：实际原文件，复制前校验 SHA-256 和大小。同一原片跨多段引用时只打包一次。

完整解压后再打开 HTML，不要只发一个 HTML 文件。交接页是独立静态文档，不需要 Weave/账号/EXE，不会自动把素材上传到第三方。使用系统字体以减少交接体积；视频/音频编码与公司浏览器策略仍可能影响本地播放。

交接只包含当前段落和关联原片，不包含已移除段落、未关联素材、原始粘贴历史、旧镜头 Prompt、素材来源网址等私有字段。批注和正文会交给接收者，请自行检查内容。若有素材在回收站或校验不符，会停止导出；不会制造一个缺素材却提示成功的包。

本机浏览器交接打包暂限制为关联媒体总计 300 MB；超过后需拆分项目/交接，避免占用过多内存。下载提示只代表发起下载，请在下载列表确认保存结果。

## 保存与升级

文稿是独立的版本化 EditDocument，段落有稳定 ID，保存在工程记录内，不只留在页面或 localStorage。浏览器本机项目写入原 IndexedDB；授权目录项目随校验提交落盘，提交失败回滚工作缓存。新增功能没有重建或清空旧项目数据库，也没有自动改动旧镜头。

完整工程请使用「导出项目 → 完整备份」，并从「全部项目 → 恢复备份」校验后恢复为独立项目；交接包不是完整工程备份。浏览器恢复 ZIP 有 512 MB 压缩包、1 GB 解压后大小上限，较大项目应另存并备份整个项目目录。旧发布的 EXE 不会因为页面源代码变更自动更新。
