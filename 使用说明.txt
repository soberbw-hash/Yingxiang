映箱 · 视频创作工作台  Windows 便携版
================================================================

一、怎么打开
----------------------------------------------------------------
这个文件夹里只有三样东西：

    映箱              ← 双击这个（正常打开）
    映箱-公司          ← 打不开时点这个（公司兼容模式）
    程序\             ← 程序本体，别动，也别往里放东西

双击「映箱」就行。第一次打开会慢一些（要初始化缓存，
可能等 5~20 秒），之后再开会快很多。打开后窗口标题是
「映箱 · 视频创作工作台」。

「映箱」和「映箱-公司」只是指路的快捷方式，真正的程序在
「程序」文件夹里那个 映箱.exe。所以：

    双击「映箱」如果提示找不到程序，或者干脆一点反应都没有，
    别怀疑文件坏了 —— 直接进「程序」文件夹，双击里面的
    映箱.exe，一样用。


二、公司电脑打不开怎么办
----------------------------------------------------------------
如果双击「映箱」没反应、闪一下就没了、或者白屏，
改用「映箱-公司」。

它启动的是同一个程序，只是额外关掉了几个在企业电脑上
容易被拦截的机制：

    --no-sandbox
        关掉 Chromium 沙箱。公司安全软件（联软、深信服、
        天珣、IP-Guard 之类）往进程里注入自己的模块时，
        沙箱会直接拒绝启动。

    --disable-gpu
        关掉显卡加速，改用软件渲染。显卡驱动被安全软件挂钩、
        或者版本太老时，白屏、花屏基本都是这个原因。
        代价是滚动稍微没那么顺，功能不受影响。

    --disable-dev-shm-usage
        不走共享内存那套，避免内存配额被限制时报错。

    --disable-features=RendererCodeIntegrity,NetworkServiceSandbox
        关掉渲染进程的 DLL 签名校验。很多公司的终端管控会把
        自己的 DLL 全局注入到每个进程里（这台机器上就有
        Vozokopot.dll），Chromium 会把这些未签名 DLL 判为非法
        并让渲染进程崩溃 —— 表现就是只剩一个空窗口，白屏。

如果「映箱-公司」还是不行，按顺序排查：

    1. 右键 程序\映箱.exe → 属性 → 看最下面有没有
       「解除锁定」勾选框。有就勾上，确定，再试。
       （从网上/聊天软件传过来的文件都会被加这个标记）

    2. 把整个「映箱」文件夹从桌面挪到别处，比如
       C:\Users\你的用户名\映箱
       桌面如果有同步盘（OneDrive、坚果云、百度网盘），
       或者公司策略禁止从桌面运行程序，会直接拦掉。

    3. 问 IT 一句：这个 exe 是不是被 AppLocker 或
       「应用程序控制策略」拦住了。如果是，只能让他们
       加白名单，换什么启动方式都没用。

    4. 右键 程序\映箱.exe → 以管理员身份运行。

    5. 还是不行，把现象告诉我（黑框一闪、白屏、弹窗写的
       什么字），我再针对性处理。


三、「待整理」是干什么的
----------------------------------------------------------------
它不是你的项目，是本机的中转站。

    在 设置 → 自动接收 里指定一个文件夹（比如浏览器的
    下载目录），之后凡是放进那个文件夹的新素材，都会
    自动出现在「待整理」里，不用手动导入。
    再在「待整理」里选中素材，用「加入项目」分给具体
    项目。

几点说明：

    · 只读取，不会搬走或删除原文件。
    · 选文件夹时里面已有的文件不会被倒灌进来，只有之后
      新增的才会自动接收；同一个文件也不会重复导入。
    · 不想用就无视它，不影响你手动导入素材。
    · 打开软件默认停在「全部项目」页面，不会强行把你丢
      进「待整理」。


四、数据存在哪
----------------------------------------------------------------
程序和你的素材是分开的。

    程序      = 这个「映箱」文件夹，可以整个挪走、整个覆盖升级
    项目      = 你自己建的项目文件夹，里面是素材和项目记录
    配置      = C:\Users\你的用户名\AppData\Roaming\Weave
                （窗口布局、最近打开、AI 接口设置等）

备份只复制「项目文件夹」就够了，那才是你的内容。
覆盖升级程序不会动项目数据；但别把项目文件夹建在
「程序」文件夹里面，升级时会被一起覆盖掉。


五、卸载
----------------------------------------------------------------
不写注册表、不装服务、不创建开机启动项。
不想要了，直接删掉整个文件夹。
想连配置一起清掉，再删 AppData\Roaming\Weave 那个目录。


六、给维护的人
----------------------------------------------------------------
本目录是打包产物，不含源码。

    npm run build                       构建前端
    node scripts/package-desktop.mjs    打包（输出 release/映箱）
    node scripts/make-icon.cjs          从 SVG 重新生成图标
    node scripts/preview-icon.cjs       预览 16~128px 各档图标

安全软件可能长期占用旧产物导致打包失败，换一个输出目录：

    WEAVE_RELEASE_DIR=release-build node scripts/package-desktop.mjs

命令行启动打包版前要清掉 ELECTRON_RUN_AS_NODE 环境变量，
否则 Electron 会退化成纯 Node 运行，表现是有进程但没窗口
（双击启动不受影响）。

图标有两个源文件：icon.svg 用于 32px 及以上，
icon-small.svg 用于 16/24px（这个尺寸下细节会糊成色块，
所以单独做了简化的重对比版本）。
